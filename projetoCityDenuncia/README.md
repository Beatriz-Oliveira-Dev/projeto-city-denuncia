# City Denúncia

Sistema web para registro de denúncias urbanas desenvolvido em Java com Spring Boot.

## Tecnologias utilizadas

- Java 21
- Spring Boot
- Spring MVC
- Thymeleaf
- Maven
- H2 Database
- HTML/CSS

## Funcionalidades atuais

- Página inicial
- Tela de login
- Tela de denúncia
- Estrutura backend Spring Boot
- Controller
- Service
- Repository
- Entity Denuncia
- Integração frontend + backend

## Estrutura do projeto

```bash
src/main/java
├── controller
├── model
├── repository
├── service

src/main/resources
├── templates
├── static
```

## Como executar

1. Clonar o repositório

```bash
git clone URL_DO_REPOSITORIO
```

2. Abrir no IntelliJ

3. Executar:

```bash
ProjetoCityDenunciaApplication.java
```

4. Abrir:

```bash
http://localhost:8080
```
